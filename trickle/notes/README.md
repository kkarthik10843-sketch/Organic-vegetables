# AgriDirect - Smart India Hackathon Project (SIH26033)

**Tagline:** From Farm Directly to You
**Goal:** Create a digital platform that directly connects farmers with consumers/buyers and reduces unnecessary intermediaries.

## Project Notes
*   This is a pure frontend implementation utilizing React 18 and Tailwind CSS via CDN.
*   The application mocks backend functionality using the Trickle Database API (which acts as a serverless database layer).
*   **Maintenance Rule:** Whenever major features like the marketplace, auth, or dashboards are updated, please ensure this README is updated if necessary.
